# แดชบอร์ดหน่วยส่องกล้องทางเดินอาหาร

แดชบอร์ดสถิติรายเดือนของหน่วยส่องกล้องทางเดินอาหาร ใช้งานผ่านเว็บเบราว์เซอร์ทั้งบนคอมพิวเตอร์และมือถือ
หน้าเว็บอยู่บน **GitHub Pages** ส่วนข้อมูลเก็บใน **Google Sheet** ของหน่วยงาน (ผ่าน Google Apps Script)

**ระบบที่ใช้งานจริง**
- แดชบอร์ด: https://cngis-endoscopy.github.io/endoscopy-dashboard/
- GitHub repo: https://github.com/cngis-endoscopy/endoscopy-dashboard (บัญชีหน่วยงาน cngis-endoscopy)
- ข้อมูล: Google Sheet `Endoscopy Dashboard Data` (เมนู ส่วนขยาย › Apps Script)

ภายในมี 7 หน้า: ภาพรวม · รายแพทย์ (แยกอายุรกรรม / ศัลยกรรม) · กรอกข้อมูล · ตารางข้อมูล · กล้องส่องตรวจ (สถานะ + ส่งซ่อม) · Scope of service + ตารางแพทย์ · ตั้งค่ารายการ

---

## สิทธิ์ผู้ใช้

| บทบาท | เข้าสู่ระบบด้วย | ทำอะไรได้ |
|---|---|---|
| ผู้ดูแลระบบ | รหัสผู้ดูแลระบบ | แก้ไขและตั้งค่าได้ทุกส่วน |
| ผู้บันทึกข้อมูล | รหัสผู้บันทึกข้อมูล | ดูทุกหน้า และกรอก / แก้สถิติรายเดือน |
| ผู้ชม | ไม่ต้องเข้าสู่ระบบ (หรือรหัสดูข้อมูล ถ้าตั้งไว้) | ดูได้อย่างเดียว |

สิทธิ์ถูกตรวจที่ Google Apps Script ทุกครั้งที่บันทึก ไม่ใช่แค่ซ่อนปุ่มบนหน้าเว็บ
เข้าสู่ระบบแล้วใช้งานได้ 12 ชั่วโมง

---

## ติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### ขั้นที่ 1 · สร้าง Google Sheet เก็บข้อมูล

1. เปิด [Google Sheets](https://sheets.google.com) สร้างไฟล์ใหม่ ตั้งชื่อเช่น `Endoscopy Dashboard Data`
   (แนะนำให้ใช้บัญชี Google ของหน่วยงาน ไม่ใช่บัญชีส่วนตัว)
2. เมนู **ส่วนขยาย › Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางเนื้อหาจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ในโปรเจกต์นี้ › กด 💾 บันทึก
4. กลับไปที่ Google Sheet แล้วกดรีเฟรชหน้า จะมีเมนู **แดชบอร์ด** เพิ่มขึ้นมา

### ขั้นที่ 2 · ตั้งรหัสผ่าน

1. เมนู **แดชบอร์ด › ① ตั้งค่าครั้งแรก**
2. ครั้งแรก Google จะขออนุญาต: กด **Continue** › เลือกบัญชี › ถ้าเห็นคำว่า "Google hasn't verified this app" ให้กด **Advanced › Go to … (unsafe)** › **Allow**
   (เป็นสคริปต์ที่เราสร้างเอง จึงยังไม่ผ่านการตรวจของ Google เป็นเรื่องปกติ)
3. ใส่ **รหัสผู้ดูแลระบบ** และ **รหัสผู้บันทึกข้อมูล** (อย่างน้อย 6 ตัวอักษร ใช้คนละรหัสกัน)

### ขั้นที่ 3 · เปิดใช้เป็น Web app

1. ในหน้า Apps Script กด **Deploy › New deployment**
2. กดรูปเฟือง ⚙ ข้าง "Select type" › เลือก **Web app**
3. ตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. ทดสอบ: เปิด URL นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `"ok":true` และ `ระบบหลังบ้านทำงานอยู่ ✔`

### ขั้นที่ 4 · ใส่ URL ใน GitHub

1. ใน GitHub เปิดไฟล์ `config.js` › กดรูปดินสอ ✏️ แก้ไข
2. วาง URL ระหว่างเครื่องหมาย `''` เช่น
   ```js
   apiUrl: 'https://script.google.com/macros/s/AKfy...../exec',
   ```
3. กด **Commit changes**

### ขั้นที่ 5 · เปิด GitHub Pages

1. ใน repo นี้ไปที่ **Settings › Pages**
2. Source: **Deploy from a branch** · Branch: **main** · โฟลเดอร์ **/ (root)** › **Save**
3. รอ 1–2 นาที ลิงก์แดชบอร์ดจะเป็น `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`
4. เปิดลิงก์ › กด **เข้าสู่ระบบ** ด้วยรหัสผู้ดูแลระบบ › ไปหน้า **ตั้งค่ารายการ** เพื่อตั้งค่าเริ่มต้นของหน่วย และเพิ่มรายชื่อแพทย์ที่หน้า **รายแพทย์**

## การใช้งานประจำ

- **ส่งลิงก์ให้ทีม**: ส่งลิงก์ GitHub Pages ให้ทีม แล้วแจ้งรหัสผู้บันทึกข้อมูลเฉพาะคนที่ต้องกรอกสถิติ
- **ดูข้อมูลใน Google Sheet**: เมนู **แดชบอร์ด › สร้างตารางสถิติรายเดือน** จะได้แผ่นงาน `สถิติรายเดือน` ไว้ทำ Pivot หรือส่งต่อ
- **เปลี่ยนรหัสผ่าน**: เมนู **แดชบอร์ด › ตั้งรหัส…** แล้วกด **ออกจากระบบทุกเครื่อง** เพื่อให้ทุกคนต้องเข้าสู่ระบบด้วยรหัสใหม่
- **ไม่ให้คนนอกดูข้อมูล**: เมนู **แดชบอร์ด › ตั้ง / ยกเลิกรหัสสำหรับดูข้อมูล** แล้วทุกคนต้องใส่รหัสก่อนเห็นตัวเลข
- **สำรองข้อมูล**: Google Sheet มีประวัติเวอร์ชันอยู่แล้ว (ไฟล์ › ประวัติเวอร์ชัน) หรือ ไฟล์ › ทำสำเนา เป็นระยะ

> ⚠️ ห้ามแก้แผ่นงาน `_store` ด้วยมือ เป็นที่เก็บข้อมูลของระบบ

## ข้อควรรู้ด้านความปลอดภัย

- โค้ดหน้าเว็บบน GitHub Pages (repo สาธารณะ) ทุกคนเห็นได้ แต่ **ข้อมูลอยู่ใน Google Sheet** ไม่อยู่บน GitHub
- ถ้าไม่ได้ตั้งรหัสดูข้อมูล ทุกคนที่มีลิงก์จะเห็นสถิติและรายชื่อแพทย์
- ระบบนี้ออกแบบสำหรับ **สถิติรวม** ห้ามใส่ข้อมูลที่ระบุตัวผู้ป่วย (HN, ชื่อ, เลขบัตรประชาชน) ในช่องใดๆ รวมถึงช่องหมายเหตุ
- ระบบเก็บเฉพาะค่า hash ของรหัสผ่าน ใส่รหัสผิดเกิน 8 ครั้งใน 15 นาที ระบบจะล็อกการเข้าสู่ระบบชั่วคราว

## เมื่อแก้โค้ด Apps Script

หลังวาง `Code.gs` เวอร์ชันใหม่ ให้กด **Deploy › Manage deployments › ✏️ › Version: New version › Deploy**
URL เดิมใช้ได้ต่อ ไม่ต้องแก้ `config.js`

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ขึ้น "ยังไม่ได้เชื่อมต่อ Google Sheets" | ยังไม่ได้ใส่ `apiUrl` ใน `config.js` (ขั้นที่ 4) |
| ขึ้น "เชื่อมต่อข้อมูลไม่ได้" | เปิด URL `/exec` ดูว่าขึ้น `"ok":true` หรือไม่ ถ้าขึ้นหน้าให้ล็อกอิน Google แปลว่าตั้ง Who has access ไม่ใช่ **Anyone** |
| เข้าสู่ระบบแล้วขึ้น "ยังไม่ได้ตั้งค่าระบบ" | ทำขั้นที่ 2 ในเมนูของ Google Sheet |
| แก้ Code.gs แล้วไม่เปลี่ยน | ต้อง Deploy เป็น New version (ดูหัวข้อด้านบน) |

apps-script/Code.gs   โค้ดฝั่ง Google Sheets (วางใน Apps Script)
